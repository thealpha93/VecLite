VecLite browser smoke test (v0.4)

Manual verification for the browser WASM init path (VecLite.init() with no arguments — uses fetch + import.meta.url). Covers all v0.4 features including veclite/rag.

Section 9 (veclite/rag) requires an internet connection — the embedding model (~23 MB) is downloaded from HuggingFace on first run and cached by the browser.

To run: npx serve . -p 3000 then open http://localhost:3000/docs/smoke-test.html
